Only editions with known planned updates are listed here; if no known planned updates exist, the edition is left out.

Java Edition

26.4

Main article: Java Edition 26.4

26.4, the release of the fourth game drop of 2026, is a game drop set to release in the fourth quarter of 2026, which adds the ice caves biome, including frostbites.

Vibrant Visuals update

The Vibrant Visuals system is planned for implementation in an unspecified future update. No specific version number has been provided for when it will be implemented, as the current focus is based on refactoring graphical and rendering related systems in preparation.[2][3][4]

Bedrock Edition

26.60

Main article: Bedrock Edition 26.60

26.60 is a minor update set to release on October 27, 2026, which introduces a native version of Bedrock Edition for the Nintendo Switch 2.[5][6]

Support for Vibrant Visuals will be included in this release, unlike the original Nintendo Switch version which runs on the Nintendo Switch 2 via backward-compatibility.[7] The render distance will also be increased from 12 to 28 chunks without Vibrant Visuals.

Together with this release, the Super Mario Mash-up, bundled with Nintendo platforms, will be updated for Vibrant Visuals. Additionally, newly purchased Minecoins will no longer be cross-platform available between Nintendo platforms and other platforms.[8]

A closed beta of this native release has been released for limited players on the Nintendo Switch 2.
