The Minecraft Launcher is the main game downloader and launcher for Java Edition, Bedrock Edition, Minecraft Dungeons, Minecraft Dungeons II and Minecraft Legends on PC. It is available for Windows, macOS and Linux, but Minecraft: Bedrock Edition, Minecraft Dungeons, and Minecraft Legends can be played only on Windows.

Features

[edit | edit source]

On the initial login screen, users must log in with a pre-existing Microsoft account, otherwise they can create a new one by clicking the link. Subsequent logins can be done in the "Settings" tab.

On the left side, all tabs can be selected. The launcher version is shown in the bottom-left.

Home

[edit | edit source]

The "Home" tabs contains a button to play, with a dropdown allowing to select a game and installation, as well as Quick Play links. The Home tab also shows the player's Minecoin balance with a link to purchase more, and a button to open the Inbox with Bedrock Edition news messages.

The rest of the page is filled with promotions and minecraft.net news articles.

Account

[edit | edit source]

The top left corner of the Minecraft Launcher contains the user's Xbox gamertag for the currently active account (which might differ from their Java Edition username[2]). Clicking on it shows a dropdown:

  • Help, with links to various support websites, official social media, and the Minecraft Wiki and Planet Minecraft.
  • Manage profile, opening the player's Profile page similar to the one on minecraft.net. Players can view their games, account information, Realms, and Bedrock Edition profile information here, as well as various external links.
  • A link to the profile page on minecraft.net, with mostly the same options.
  • Log out
  • An account selector. Multiple accounts can be stored only on Linux and macOS, and can be switched here.
  • View all accounts, opening the Account settings.

Minecraft: Java Edition

[edit | edit source]

There are 5 tabs on the Java Edition page: Play, Installations, Realms, Skins, and Patch notes.

The main "Play" tab allows the user to download (if needed) and launch Minecraft: Java Edition with the "Play" button, and also includes an installation selection on the left (which sorts installations by last played), the user's Java Edition username on the right, and a list of the latest news for the game from minecraft.net below.

  • One can launch multiple instances of the game by pressing the "Play" button while the game is running.
  • If the device is not connected to the internet, the game can be run in offline mode, but only if the game has been initially downloaded.
  • If the user isn't logged into an account that has purchased the game, the "Play" button appears as a "Buy Now" button that links to Buy Minecraft on Minecraft.net.

Installations

[edit | edit source]

In the "Installations" tab, custom installations can be created and edited. There are buttons to sort and search installations, as well as checkboxes to enable installations with "Releases", "Snapshots", and "Modded" versions of the game. Installations are stored in launcher_profiles.json (in the game's directory (.minecraft).

By default, there are installations for the "Latest release" and for "Latest snapshot" (if enabled), both of which the game versions cannot be changed. A new installation can be created by clicking the "New installation" button and an existing installation can be edited by clicking on it. There is a "Play" button that launches the selected installation and a folder icon that takes to the installation's game directory. The ellipsis button contains options to edit, duplicate, or delete an installation.

On the create/edit installation page, the following can be changed:

  • Icon, by selecting one of the default ones or adding a custom one. Custom icons must be a .png and 128×128 pixels in size.
  • Name, by default called "<unnamed installation>".
  • Version, which includes access to older releases and snapshots (if enabled).
  • Game directory, the location of where the game files are saved, the default being .minecraft. The location can be typed in or selected using the "Browse" button.
  • Resolution, which changes the game's window size. It has a list of resolutions, or a custom one can be typed in.
  • Java executable, by default uses the bundled Java runtime.
  • JVM arguments, such as heap size or enabling debug renderers not normally accessible in the debug screen such as mob pathfinding.

Previously, it was possible for users to manually set a logging configuration (see Debugging for more info), however, this doesn't seem to work anymore.[3]

A specific game version's server jar can also be downloaded by selecting the version in the list and pressing the "Server" button next to it.

Backward compatibility

[edit | edit source]

The Minecraft Launcher has the ability to play most older releases of the game (and older snapshots, if enabled) by default, but also some older versions prior to Java Edition 1.0.0. In order to see these versions in the "Installations" tab, the player must enable "Show historical versions of Java Edition" in the Minecraft Launcher "Settings" tab. Because these versions are outdated and unsupported, they may contain bugs and errors that are not present in newer versions. It is recommended to run old versions of the game in a separate directory and backup worlds to avoid save corruption or other problems.[4]

Once historical versions are enabled, the following can be accessed:

  • Most Beta versions.
  • Most Alpha versions (however, Alpha v1.2.0 and Alpha v1.2.1 are duplicates of Alpha v1.2.0_02 and Alpha v1.2.1_01 respectively).
  • One Infdev version.
  • Four Classic versions.
  • Five pre-Classic versions (however, rd-20090515 is a duplicate of rd-161348).[5]

This list of versions is populated by version_manifest.json.

Some issues with these older versions include:

  • Some sounds are wrong; bows, doors, and explosions use their sounds from RC1, even in versions released prior to it. In versions before Alpha v1.1.2_01, sounds do not work at all.
  • Skins and capes are missing in versions prior to 1.7.6, as earlier versions used a different skin server, which has since been shut down.
  • In Alpha v1.0.15 and from Alpha v1.2.0 to Alpha v1.2.6, the Minecraft Launcher does not set the player's name properly, resulting in everyone using default names: "Player" followed by a random 3-digit number. This makes multiplayer difficult to play, as a player's location and inventory is reset every time they relaunch their client.
  • In Alpha v1.2.5 and Alpha v1.2.6 specifically, players are always named "Player524". Playing multiplayer in these versions is impossible, as joining a server kicks off other players with the same name.
  • As a side effect of the above, and as a result of old authentication servers being shut down, online mode no longer works in versions before Beta 1.8.

Realms

[edit | edit source]

In the "Realms" tab, the user can buy, quick play, and manage a Minecraft Realm. Players can choose their installation of choice before launching a realm.

Skins

[edit | edit source]

In the "Skins" tab, the user can view and change their in-game skin. By default, the skin is either Steve, Alex, Noor, Sunny, Ari, Zuri, Makena, Kai, or Efe.

In the skin library, a skin can be applied by clicking "Use". The skin can also be edited, duplicated, chosen to be either wide or slim, or delete by clicking the ellipsis button. By default, the library contains the default Steve, Alex, Noor, Sunny, Ari, Zuri, Makena, Kai, and Efe skins, which can be duplicated or applied, but not removed. Custom skins can also be uploaded by clicking the "New skin" button.

Visiting this tab without purchasing the game displays a button that redirects to the Minecraft: Java Edition store page.

Patch notes

[edit | edit source]

This tab shows cards of the patch notes. Each card contains an image on top and the text below stating the name of the patch notes. When clicked, this displays the patch notes.

Minecraft: Bedrock Edition

[edit | edit source]

There are 7 tabs on the Bedrock Edition page: Play, Realms, Creator Tools, Marketplace Pass, FAQ, Installation, and Patch notes (the "Installation" tab is not shown on unsupported platforms). On the top-right, a bell icon links to the Inbox.

The main "Play" tab allows the user to download or purchase (if needed) and launch Minecraft: Bedrock Edition[6] with the "Play" button and also includes an installation selection on the left to choose between the latest release or the latest Preview. The Minecoins balance is shown on the right which opens a Minecoins purchase screen when clicked. The latest game news from minecraft.net and system requirements are shown in a scrollable section below. Quick Play is accessible and can be managed from the top-right.

  • If the device is not connected to the internet, the game can be run in offline mode, but only if the game has been initially downloaded.
  • If the user is on an unsupported device, a warning appears with a link to a website with supported devices, and the "Play" button is replaced with "Not Playable on this Device".
  • If the user isn't logged into an account that has purchased the game, the "Play" button appears as a "Play demo" button that links the player to Microsoft Store to download and launch the demo version of the game.

The "Play" tab is decorated with key art from the latest named update and allows update music to be played. There can also be advertisements and there is a gift purchase.

Realms

[edit | edit source]

In the "Realms" tab, the user can buy, join, and manage Realms. Owned and joined Realms are shown with some server information, and a list of pending invites. Joined Realms can be left from here, but all other settings can only be managed in-game or from the minecraft.net page linked here.

Creator Tools

[edit | edit source]

In the "Creator Tools" tab, the user can launch Bedrock Edition with the Editor tools enabled, where players can use the advanced in-game tools to edit worlds through projects and export them as world templates, and create custom Vibrant Visuals resource packs. The Editor can be launched for both the latest release and Minecraft Preview.

This tab includes links to articles about Blockbench plug-ins, Chunker, and the feedback site.

Marketplace Pass

[edit | edit source]

In the "Marketplace Pass" tab, the user can subscribe to the Marketplace Pass and access over 150 Marketplace content that changes every month. The links to packs and the subscribe page launch Minecraft with the respective pack or subscribe page opened in the Marketplace. Furthermore, this section contains information about the Marketplace Pass, the Marketplace in general, and Realms Plus, as well as links.

Command-line usage

[edit | edit source]
On Windows, these options only apply to the old Unified Minecraft Launcher and not the Microsoft Store version.

The Minecraft Launcher can be invoked using the command line by typing %ProgramFiles(x86)%\Minecraft Launcher\MinecraftLauncher.exe on Windows, minecraft-launcher on Linux or /Applications/Minecraft.app/Contents/MacOS/launcher on macOS.

As of version 3.37.2, the Minecraft Launcher provides several command-line options:

  • -h, --help – Displays a help message listing standard command-line options.
  • -w, --workDir <path> – Sets the launcher working directory (the location of the .minecraft directory).
    • Can be used to create a portable installation of the launcher by passing a custom path or --workDir . to use the current directory.
  • -l, --lockDir <path> – Restricts the launcher installation directory to the specified folder.
  • -c, --config <path> – Specifies a custom path to a configuration file for the launcher.
  • --clean – Deletes the game and runtime directories, including their contents, from the working directory.
  • --launcherui – Starts the launcher directly in UI mode, skipping update and startup checks. Allows multiple launcher processes to run simultaneously.
  • --mclAllowProcessLockRetries – If another instance of the launcher is already running, retries starting up to 5 times (waiting 1 second between attempts) before bringing the existing window to the front.
  • --launcherComponentDir <path> – Specifies an alternative directory to locate and store core launcher components (such as launcher.dll). Bypasses ordinary update checks if valid components are already present in the folder.
  • --stagingDir <path> – Specifies a custom staging directory where the updater downloads, extracts, and verifies component update files before replacing active files.
  • --skipUpdate – Skips the automatic check and download of launcher updates.
  • --repair – Tells the installer to start a repair routine for the launcher and closes immediately.
  • --disableGPU – Disables GPU hardware acceleration inside the launcher interface, which can help resolve rendering glitches.
  • --debugGPU – Opens a dedicated debugging window showing GPU driver capabilities and hardware acceleration statistics for troubleshooting.

Minecraft Unified Launcher

[edit | edit source]

The Minecraft Unified Launcher (referred to on minecraft.net as the "Windows Legacy" launcher) was the traditional desktop application used to install and update Java Edition and Minecraft Dungeons prior to the introduction of the Microsoft Store version. Distributed primarily as a standard Windows installer, it installed to %ProgramFiles(x86)%\Minecraft Launcher and ran independently of modern Windows apps.

With the release of the updated Minecraft Launcher for Windows (distributed through the Microsoft Store), the Unified Launcher was deprecated on modern versions of Windows to streamline account management and cross-title support for Bedrock Edition and Xbox Game Pass. While modern installations rely on the Store package, the legacy standalone binary format remains relevant for older Windows environments and command-line usage.

  • Game crashes are reported to Mojang Studios through Hopper.
  • The legacy Minecraft Launcher can be downloaded here (version 1.6.93, ~4.6MB as opposed to the modern launcher's ~85MB). However, the legacy Minecraft Launcher is incompatible with Microsoft accounts and was discontinued in Q2 2021 due to account migration.
  • In version 2.3.240, the pig on the Minecraft Launcher screen was given a crown in light of popular Minecraft YouTuber Technoblade passing away due to cancer.
  • The Armadillo loading screen animation is scaled to 1280×720 (16:9) but was originally 646×364 (≈16:9.02), causing distortion to the animation.
