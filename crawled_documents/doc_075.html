This article describes a planned feature.[1]
It has not appeared in any development versions yet, but is planned to be included in a future update.

A blub is a planned "rabbitlike"[2] passive mob that can squeak. It can be found in the Sift, which is planned to release sometime in 2027.

History

[edit | edit source]

Announcement

[edit | edit source]
For the prior history of the blub in Minecraft Dungeons II, see Dungeons II:Blub § Announcement.
September 26, 2026 The blub is announced at Minecraft LIVE – September 2026.
The audio description of the video identifies blubs as being "rabbitlike" and describes "its glowing body jiggling slightly with each step" it takes.[2]

Quotes

[edit | edit source]
“

Under a teal blue sky, tufts of soft orange grasses sit on a hilltop. A tiny rabbitlike blub walks casually through the grasses. Its glowing body jiggling slightly with each step. It peers curiously at us, then walks off, as text appears: The Sift is coming to Minecraft Bedrock & Java Edition.

„
— Minecraft LIVE audio description
