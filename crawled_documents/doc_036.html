26.70.20 is a minor release for the Bedrock Editor released on October 13, 2026.[1][2]

Contents

  • 1 Additions
  • 2 Fixes
  • 3 References
  • 4 Navigation

Additions

[edit | edit source]
  • Added support for filter icon tooltip on the Editor List View control.
  • Added group sorting, dynamic height configuration and noMargins style for IListPanePropertyItem API.

Fixes

[edit | edit source]
  • Fixed a bug where the selected chunks are not reflecting the biome changes in Biome Data Assignment Tool.
  • Fixed an assert that occurred when interacting with Party invite toast using its hotkey in Editor mode.
  • Fixed a bug where the Custom Time UI element would remain invisible if the Presets dropdown was changed by changing the Daylight Cycle dropdown.
  • Fixed an issue that was allowing to create multiple empty layouts.
  • Fixed a bug where the tooltip on the action item for Layouts Management was inconsistent.
