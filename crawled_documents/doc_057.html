The End portal block is a block generated when an End portal or exit portal is activated, which teleports the player between the Overworld and the End.

It is one of two blocks that use the starfield effect.

Obtaining

[edit | edit source]

The End portal block cannot be obtained as an item even by using the /give command. The item form is non-existent in Java Edition, but it can be obtained through add-ons, external editors, or by using bugs in Bedrock Edition.

The End portal block can be placed using commands such as /fill or /setblock.

Natural generation

[edit | edit source]

End portal blocks can rarely generate as part of an active End portal in a stronghold, which has a one-in-a-trillion chance of generating with 12 eyes of ender.

Post-generation

[edit | edit source]

When an End portal is activated by putting an eye of ender on each empty End portal frame, the End portal blocks are generated.

The End portal blocks generate in the End podium when the ender dragon is defeated.

Usage

[edit | edit source]

End portal blocks can be used to teleport into and out of the End. When a player or other entity in the Overworld or the End touches an End portal block, it is instantly taken to the other dimension. If a single portal block is placed using commands, it can still be used to travel between dimensions.

All entities traveling to the End appear on the obsidian platform, recreating it if necessary. Players traveling to the Overworld appear at their individual spawn point, while other entities appear at the world spawn point.‌[Java Edition only]

End portal blocks render when held by endermen in Java Edition,[1] but not in Bedrock Edition.[2]

Properties

[edit | edit source]
  • Entities which touch the End portal (who have already seen the credits) are teleported to another dimension:
    • If the block is in the Overworld, the Nether, or in a custom dimension, the entity is teleported to the obsidian platform in the End.
    • If the block is in the End, they are teleported to their spawn point:
      • Players with an unobstructed respawn location (set by using a bed or respawn anchor) are teleported to that location.
      • Players whose respawn location is unset or obstructed are teleported to a small area centered on the world spawn point.
      • All other entities (aside from the exceptions listed below) are teleported exactly to the world spawn point.
    • In Java Edition, ridden entities and their passengers can use End portals (and Nether portals); in Bedrock Edition, they cannot.
      • However, in Java Edition, if an entity ridden by a player who has not yet seen the credits enters an End portal in the End, the entity will not be teleported to the world spawn.
    • Ender dragons cannot use End portals.
    • Withers can use End portals only in Bedrock Edition.
  • End portal blocks can be destroyed in Creative mode. This does not affect adjacent End portal blocks.
  • The top surface of an End portal is 3⁄4 the height of a full block.[verify]
  • The End portal is one of the only blocks without a conventional texture or entity texture; it instead duplicates and layers a star-field pattern that follows the player's cursor.
  • If TNT is detonated on an End portal, no blocks in its blast radius are destroyed.
  • If the End portal block is generated in the block grid using the debug mode world type, it teleports the player to the Overworld regardless of which dimension it is in.
  • In Bedrock Edition, it's impossible to see the texture of the End portal block when the player is under it.

If a player has not seen the credits yet, they are unloaded and shown the credits sequence. Then, they are teleported following the steps above.

Light

[edit | edit source]

End portals have a light level of 15, the brightest possible. With the "Render Dragon Features for Creators" experiment, End portals have a light color of
 #6c70b2.

Piston interactivity

[edit | edit source]

End portal blocks cannot be pushed by pistons. They also cannot be pushed or pulled by sticky pistons.
