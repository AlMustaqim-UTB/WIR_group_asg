Beta 26.70.20 (ChromeOS, Android, Nintendo Switch 2) or Preview 26.70.20 (Windows, iOS, iPadOS, Xbox, PlayStation), also known as 1.26.70.20 Beta/Preview, is the first Beta/Preview for Bedrock Edition 26.70, released on October 11, 2026, for iOS and iPadOS, and on October 13, 2026, for all remaining devices,[1] which adds crevasses, brittle ice and jukebox playlists, and fixes bugs.

This version was released for the Nintendo Switch 2 closed beta on October 16, 2026, being the seventh closed beta.

Additions

[edit | edit source]

Blocks

[edit | edit source]

Brittle ice

  • A fragile ice block that generates naturally in ice caves.
  • Can be created when water touches blue ice.
  • Breaks when standing for too long or jumping on them. Its crack level stages do not reset.
    • Frostbites standing on brittle ice do not break it.
  • Produces particles during its first stage or when it breaks.
  • Emits vibrations when its crack level changes.
  • Can only be obtained with Silk Touch.

Changes

[edit | edit source]

Blocks

[edit | edit source]

Icicle

  • The sides of the block now render brighter.
  • Now have the correct size.

Jukebox

  • Textures changed from .
  • Placing a single chest, trapped chest, or copper chest above a jukebox will apply music discs inside to the jukebox as a playlist.
    • A disc is automatically injected in the jukebox, and put back in the chest when the track finishes. This will automatically continue with all tracks in the chest, in slot order. After the last disc finishes, the first will be repeated.
    • Ejecting the current disc skips to the next available disc.

Items

[edit | edit source]

Arrow of Freezing

  • Updated the Freezing tipped arrow texture from to match other tipped arrows.

Mobs

[edit | edit source]

Frostbite

  • Can now pick up and use spears, though they do not use the charge attack.

Zombified piglin

  • Unarmed piglins and piglin brutes now remain unarmed when transforming into zombified piglins.

World generation

[edit | edit source]

Ice caves

  • Added crevasses to the ice caves, generating with brittle ice and water pools.

General

[edit | edit source]

Closed captions

  • Added generic closed captions to jump and land sounds.

Experiments

  • Removed the "Drop 4 of 2026" experiment and implemented all features in vanilla gameplay.

Marketplace

  • Added support for purchasing Marketplace content as gifts for friends.

Realms

  • Realms FAQ scrollbars now update when sections are expanded.
  • The new Realms information screen's "Learn more" button disappears for a player once they have clicked it the first time.
  • The Realms Hub's "Learn more" section now contains a button linking to a website with Realms tutorials, or contains a QR code for the player to access the tutorials.

Server

  • Added optional dedicated server performance warnings with configurable tick-time thresholds and notification cooldowns.

UI

  • Added store row names to text-to-speech.
  • Screen narration now reads slider values the way they are displayed.
  • A skin or offer is now focused by default when entering the character edit screen.
  • Pack downloads on Windows will be stored as blobs to mitigate partial deletion of cached pack content by Windows Disk Management.
  • Bopomofo and Bopomofo Extended characters now use consistent full-width spacing alongside Chinese text.
  • Updated the Inbox Feedback tab on consoles to direct players to feedback.minecraft.net.
  • Japanese and Chinese text now displays correctly on the Marketplace's "My Library" button on mobile.
  • Profile images now update correctly when the selected character appearance changes.
  • New Player Path mode and difficulty card illustrations no longer flicker or resize when the screen first appears.
  • Changed Block Light Quality options to Low, Medium, High, and Ultra, though their functionality remains the same.
  • Added responsive Marketplace store rows for browsing content cards.
  • Marketplace offers that are incompatible with the player's device now remain visible with purchase buttons disabled.
  • The "Play" button on the updated main menu has been renamed to "Play Preview" when in Preview; "Play Beta" when in beta.
  • The game version is now displayed with an "1." on the updated main menu.
    • The Editor main menu now distinguishes Preview versions.
    • A "Preview" suffix is added to Preview versions and "Beta" suffix is added to beta versions.
  • Re-added the "Get started" screen, with Ore UI.

Technical

[edit | edit source]

API

  • Script API string arguments now preserve embedded NUL (\0) characters instead of being truncated.
  • Added additional error context information when an exception is thrown inside of an event callback.
  • Added Newline and whitespace changes to the formatting of the stack error context for exceptions.
  • Released @minecraft/server version 2.12.0.
  • Added @minecraft/server version 2.13.0-beta.
  • Added topCloseButtonVisible property to CustomFormOptions in @minecraft/server-ui beta.

Blocks

  • Added the minecraft:jukebox_playlist_source block component.
    • Marks a block as a source of music discs for a jukebox directly below it.
    • Requires a compatible single container.

Block components

  • Doors:
    • The upper half of a door now reports the same open_bit block state as the lower half, rather than always reporting the door as closed. This covers doors placed by players, doors generated as part of a structure, and doors in existing worlds, which are corrected the first time their chunk loads.
  • Repeater:
    • Repeater blocks now expose a locked block state that is true while a powered repeater or comparator is feeding one of the repeater's side inputs.
    • For new worlds (base game version 1.26.60 and later), repeater locked state changes now trigger neighbor block updates for parity with Java Edition; existing worlds keep the prior client-only update behavior.
  • Scaffolding:
    • Scaffolding blocks now expose a bottom block state that is true when the block below provides no support and is not another scaffolding.
    • For new worlds (base game version 1.26.60 and later), scaffolding bottom state changes now trigger neighbor block updates for parity with Java Edition; existing worlds keep the prior client-only update behavior.

Entity components

  • The minecraft:transformation component now preserves empty equipment slots when preserve_equipment is set to true.
  • Made schema for the minecraft:annotation.break_door component stricter when parsing and will fail to load an entity json that has invalid data in versions 1.26.60 and newer.
  • Made schema for the minecraft:attack component stricter when parsing and will fail to load an entity json that has invalid data in versions 1.26.60 and newer.
    • damage now only accepts a scalar or an object with min and max values. Array values are no longer valid.
  • Made schema for the minecraft:inventory component stricter when parsing and will fail to load an entity json that has invalid data in versions 1.26.60 and newer.
  • Made schema for the minecraft:spell_effects component stricter when parsing and will fail to load an entity json that has invalid data in versions 1.26.60 and newer.
  • The minecraft:can_stand_on_brittle_ice component enables any mob to stand on brittle ice without breaking it.
    • Used by defining the component as follows: "minecraft:can_stand_on_brittle_ice": {}

Features

  • Added the internal-only minecraft:crevasse_feature world generation feature, which carves a winding, tapered crevasse into exposed terrain.
    • This feature is not currently available for use in creator content.
    • The crevasse follows the terrain surface, extends in opposite directions from its placement position, and requires a minimum connected footprint before carving.
      • The following fields configure generation:
        • max_length: Maximum end-to-end length in blocks, from 4 to 16; defaults to 16.
        • max_width: Maximum cross-section width in blocks, from 2 to 8; defaults to 4.
        • min_footprint: Minimum connected horizontal footprint required before carving, from 1 to 32 blocks; defaults to 10.
        • twistiness: Amount of horizontal curvature, from 0.0 to 16.0; defaults to 4.0.
        • carve_depth: Range used to select the carve depth below the origin terrain surface, from 4 to 32 blocks; defaults to [6, 10].
        • fill_depth: Range used to select the fill depth below the origin terrain surface, from 0 to 32 blocks; defaults to [4, 6].
        • surface_block: Optional block placed over the crevasse opening; omitted by default.
        • fill_block: Optional block placed at or below the selected fill depth; omitted by default.

Packs

  • System packs can no longer be overridden by development packs with the same identity.

Points of Interest

  • Released support for defining point-of-interest types with hierarchical tags in behavior packs.
  • Released /locate poi for locating registered points by type or tag.

UI

  • Downloading Marketplace content no longer deletes development resource, behavior, or skin packs with matching UUIDs.
  • Malformed JSON UI in resource packs (unresolved control names, invalid anchors, unknown control types, unsolvable layouts, malformed binding expressions, and view binding loops) is now reported as a content log error.
  • Route transitions are now built from animation selectors with createRouteTransition, so an animation is data that can depend on the from/to navigation pair rather than a bespoke transition component.
  • Route transitions now live in the standalone @mojang/react-route-transition package, with the screen animation setting in @mojang/react-screen-animation, so both can be consumed without depending on @mojang/ui.

Experimental

[edit | edit source]

These additions and changes are accessible by enabling the "Beta APIs", "Upcoming Creator Features", "Render Dragon Features for Creators", and new "Nether Spawning Rebalancing" experimental toggles.

Changes

[edit | edit source]

Mobs

[edit | edit source]

Mob spawning

  • The spawning mechanics in the Nether have been overhauled to better match Java Edition.
    • Currently, it only affects enderman spawning.[2]

Technical

[edit | edit source]

API

  • Updated the ScriptPlayer.playMusic method in beta for playing music tracks for an individual player.
    • Now returns a SoundInstance when the MusicOptions.fade value is zero or not given.
    • Returns undefined when the MusicOptions.fade value is greater than zero.
    • Can now pass a SoundDefinition into the trackId field.
  • Updated the ScriptWorld.playMusic method in beta for playing music tracks for all players in the world.
    • Now returns a SoundInstance when the MusicOptions.fade value is zero or not given.
    • Returns undefined when the MusicOptions.fade value is greater than zero.
    • Can now pass a SoundDefinition into the trackId field.
  • Added support for the minecraft:chiseled_bookshelf block to BlockInventoryComponent in beta.
  • Added ItemBlockEntityStorageComponent item component behind beta.
    • It may be accessed on any item-stack.
    • It has the following methods: store, release, transfer, getEntities and size which work like their BlockEntityStorageComponent counterparts.
      • release however takes an extra position parameter to decide where the entity is being released.
    • The component will be pre-populated if the item-stack results from a successful carry_over_block_entity_data loot function.
    • Stored entities will be carried over the corresponding placed block if it supports entity-storage.
  • CarryOverBlockEntityDataFunction:
    • Added the read-only beta property entityStorage to expose whether the loot function carries stored entities from the block entity to the dropped item.

Blocks

  • Added the optional Boolean field entity_storage to the carry_over_block_entity_data loot function, defaulting to false and requiring the Upcoming Creator Features experiment.
  • When entity_storage is true, stored entities are copied from the block entity to the dropped item without being released, independently of the dynamic_properties option.
  • Placing the dropped item restores its stored entities when the placed block supports entity storage, without releasing them.
  • Split BlockComponentNamedTickEvent's isName into name and isMine.
    • name is a string property matching the name used when ScriptBlock.scheduleNamedTick was used.
    • isMine is a method that returns true if the event was scheduled by your pack.
  • Added two new methods to the Block API and renamed one:
    • getScheduledNamedTickCount which returns the amount of named events scheduled at a position, agnostic of pack origin.
    • getAllScheduledNamedTicks which returns the vector of named events scheduled at a position by that pack.
    • Renamed removeScheduledNamedTick to removeScheduledNamedTicks.
  • minecraft:block_entity:
    • Added the optional show_ui_on_interaction boolean to container for block format versions 1.26.20 and later with Upcoming Creator Features enabled; it defaults to true.
    • Setting show_ui_on_interaction to false disables the built-in container UI and allows normal block interaction events, including registered onPlayerInteract callbacks, to run instead; omitting the field or setting it to true preserves container opening without those callbacks.
    • Custom containers now follow chest interaction permissions, preventing container opening and interaction callbacks for players without permission to open containers, even when the UI is disabled.
    • Custom containers are now recognized as interactive container blocks, preventing duplicate client-side use of held items during interaction.
    • The HUD now shows the "Open" interaction hint for custom containers only when their UI is enabled.

Entity

  • Added beta Script API support for positioning entities as passengers of blocks.
    • Entity.startPassengerOfBlock(blockPosition, offset, rotation, rotationLimit, emote) positions an entity as a passenger of a block, with a position offset, rotation, rotation limit, and PassengerOfBlockEmoteType (Standing, Riding, or Laying).
    • Entity.stopPassengerOfBlock() stops an entity from being a passenger of a block.
    • The read-only Entity.isPassengerOfBlock property reports whether an entity is a passenger of a block.
    • Destroying or changing a block does not automatically stop an entity from being its passenger; scripts must call Entity.stopPassengerOfBlock() because blocks are agnostic of their passengers.
    • The existing query.is_riding returns true when an entity is riding a vehicle or is a passenger of a block in the Riding pose; the new query.is_laying returns true when an entity is a passenger of a block in the Laying pose. When isPassengerOfBlock is true and both queries are false, the entity is in the Standing pose for animation.

Entity components

  • Added a new experimental minecraft:time_marker_sensor entity component, available to entity definitions using the beta format version, which runs an entity event every time a named time marker fires on a named world clock.

Features

  • POI type definitions now respect behavior pack stacking order, allowing higher-priority packs to override definitions from lower-priority packs.

Graphical

  • Ice crystals now emit a light blue light color.

Fixes

[edit | edit source]

37 issues fixed

From released versions before 26.70

  • MCPE-50732 – Health bar sometimes does not flash white when you take damage or heal.
  • MCPE-65762 – Mobs spawn too frequently in the Nether.
  • MCPE-117741 – Renamed sea pickles reset their name when placed.
  • MCPE-137149 – Skeletons that transform into stray sometimes get new armor.
  • MCPE-153200 – Polar Bears do not extend their arms or look at the target when attacking
  • MCPE-160900 – Player one on split screen has giant effect icons.
  • MCPE-163495 – /setmaxplayers not available on downloaded worlds from realms.
  • MCPE-227725 – Game freezes when recording the screen.
  • MCPE-227874 – Importing .mcpack, .mcaddon, or .mcworld files while the game is opened no longer works.
  • MCPE-228282 – Pressing Y while the Friends drawer is opened does not close the drawer.
  • MCPE-233468 – Zombies and their variants can wear wolf, horse, and nautilus armor.
  • MCPE-237074 – Custom block precipitation interactions do not vary across permutations.
  • MCPE-237495 – Snow layers may not update to fall into snowloggable blocks.
  • MCPE-237532 – Items with "minecraft:damage_absorption" do not absorb damage if the item is enchanted with Unbreaking and receives no durability loss due to the enchantment.
  • MCPE-238783 – Percent sign (%) is evaluated as a language key lookup in some contexts.
  • MCPE-241358 – The game sometimes freezes when a player opens a chest that containing an explorer map in a abandoned camp.
  • MCPE-242595 – Ray-traced objects without PBR maps support now appear reflective (RTX/ray-traced graphics mode).
  • MCPE-243328 – Dispensers and Droppers no longer play ejection fail sounds and particles.
  • MCPE-243329 – Tripwire hooks no longer play sounds when triggered.
  • MCPE-243354 – Ore UI Minecraft logo stretches to fit frame.

Other

  • Fixed the base of an icicle visually flickering (z-fighting) with the block beneath it when viewed from a distance.
  • Fixed tooltip error where freezing displayed a rank.
  • Fixed tooltip error where freezing was listed as positive.
  • Fixed "Chat instructions on join" to show supported join instructions even in single-player worlds and with gameplay tips enabled; turning the setting off still allows contextual multiplayer tips.
  • Fixed text-to-speech not outputting time correctly when focused on realm player sessions on Realms Timeline tab.
  • Fixed a bug that caused all visible chunks to reload when resizing the game window on Windows.
  • Fixed script TextPrimitive icons being rendered behind the text background and also being impacted by lighting.
  • Fixed bug where Realm admin log would remain on loading spinner if a player's profile did not fetch succesfully.
  • Fixes a crash that can sometimes happen on PlayStation 5 when the game uses a large number of textures at once.
  • Fixed a crash that could occur when the resource pack list refreshes while a pack is highlighted.
  • Fixed a crash due to a race condition when teleporting and removing entities on the same tick.
  • Fixed the alignment of text field focus outlines.
  • Fixed the Social button on the main menu requiring two presses to open the Social Drawer after launching the game.
  • Fixed Custom Skin button occasionally not rendering and not showing the selected skin.
  • Fixed Container.setItem and ContainerSlot.setItem to clamp item stack sizes to the item's maximum stack size.
  • Fixed some scenarios where the text length was incorrectly calculated for RawText used by PrimitiveText.
  • Fixed a bug where zombies can gain new armor or tools after being converted from husks.
