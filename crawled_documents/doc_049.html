Textures in Minecraft are image files that can be rendered in-game for various purposes, such as blocks, entities, player skins, and UI elements. Color textures are RGBA images used directly for coloring and transparency of objects, while MERS textures create lighting effects with Vibrant Visuals. They can be customized with resource packs.

Usage

[edit | edit source]

In Java Edition, vanilla textures are located in assets\minecraft\textures in client.jar, while in Bedrock Edition and Minecraft Education they are in textures in the internal resource packs.

In Java Edition, all textures are in PNG format. In Bedrock Edition, four image formats are supported.[1] When multiple textures with the same name and different formats conflict, they are applied in the following order of priority:

  1. .tga
  2. .png
  3. .jpg
  4. .jpeg

TGA files‌[Bedrock Edition only] are generally used when extra information is stored in the alpha channel, including pixels that can glow in the dark, parts of the texture that are colored, or subsurface scattering on MERS textures

Tinting

[edit | edit source]

Many textures can be dynamically colored by the game. Biome-colored blocks, like leaves, take their colors from colormaps; 256×256 images where each axis corresponds to the biome climate parameters temperature and downfall.

Animated textures

[edit | edit source]

Most textures are stored on individual files and compiled into generated texture atlases for rendering. However, various older textures mostly in Bedrock Edition, are combined in predefined texture atlases. Atlases are also used to animate textures. Individual frames of the animation get stitched together in one file. Rendering of the animation is then controlled by a JSON file named texture.mcmeta‌[JE only] or an object in flipbook_texture.json.‌[BE only][2]

Types

[edit | edit source]

Blocks

[edit | edit source]
Main article: List of block textures

The textures of the blocks in Minecraft are usually done in 16×16 pixels. Some blocks have an animated texture like water, lava, portal blocks, fire, prismarine, sea lantern, sea grasses, command block and magma blocks as well as stonecutter which have an animated pattern on each side. The animated textures are presented with a series of 16×16, the play of which alternates in succession. The texture of some blocks get mirrored or rotated depending on their coordinates in the world making them look isotropic along large areas.

Items

[edit | edit source]
Main article: List of item textures

Just like the blocks, usually the textures of the items in Minecraft are also done in 16×16 pixels. Most of the item textures are static, except those for clock and compass. In Java Edition, these animated textures are many separated 16×16 images, while in Bedrock Edition and Minecraft Education they are presented with a series of 16×16.

Light block and the elements in Bedrock Edition and Minecraft Education are the only item textures done in 32×32 for officially released Minecraft versions.

Entities

[edit | edit source]
Main article: List of entity textures

Similar to the skin images, the textures of entities usually integrate images applied to all parts of an entity into one single file. Their resolution is higher than 16×16 pixels, but typically their heights and widths are multiples of 16px.

Armor textures are rendered separately on top of entities. Armor trims are separate textures rendered on top of armor textures.

Paintings

[edit | edit source]
Main article: List of painting textures

Paintings are entities with flat textures rendered on the front and a planks texture on the back, stored separately from entities.

Particles

[edit | edit source]

Particles are textures directly rendered in-game in 2D, always facing the camera. Animated particles use multiple texture files for the animation, and some sources emit particles with different textures. Various particles have gray textures, colored depending on the situation or animation. Some particles use texture atlases in Bedrock Edition.

GUI and UI

[edit | edit source]
Main articles: Java Edition GUI textures and Bedrock Edition GUI, UI, and Ore UI textures

Most objects and graphics in GUIs, UIs, and menu screens are generated with multiple textures, sometimes from texture atlases. Textures from Ore UI menu screens cannot be modified with resource packs and are stored in Content/data/gui/dist/hbui instead.

Other

[edit | edit source]
Main article: List of miscellaneous textures

There are several other textures used for in-game objects, ranging from overlays and glint effects to celestial bodies and Vibrant Visuals water caustics.
