Wood or hyphae is a block that has the log's "bark" texture on all six sides. It comes in 12 types: oak, spruce, birch, jungle, acacia, dark oak, mangrove, cherry, crimson, warped, pale oak, and poplar.

Natural generation

[edit | edit source]

Acacia wood can generate in savanna villages.

Spruce wood can generate in snowy taiga and taiga villages.

Mangrove wood can generate in some entrance rooms of trial chambers.

Usage

[edit | edit source]

Wood and hyphae can be placed in three orientations, similarly to normal logs.

Fuel

[edit | edit source]

Wood can be used as a fuel in furnaces, smelting 1.5 items per block.

Hyphae cannot be used as a fuel in furnaces.

Axes

[edit | edit source]

Using an axe on wood or hyphae turns it into stripped wood or hyphae, which acts the same as regular wood or hyphae.

Cocoa beans

[edit | edit source]

Cocoa beans can be placed on the side of jungle wood to grow new cocoa pods.

Java Edition
1.3.112w30d Wood exists as a metadata variant of the usual log block, likely implemented unintentionally as these values were never initially intended to be used. Specificially, metadata values 12-15 are used, which exceed the values use for rotation.
The item form of "wood blocks" visually appear to be wood blocks, but when placed act as normal logs. More information on this item can be found at Invalid Data Value Log.
Wood drops normal logs when broken normally, however Silk Touch results in the wood "item" version being dropped instead.[verify]
1.814w10a minecraft:log2 blocks with numerical metadata variants 2-3, 6-7, 10-11 and 14-15, which are inaccessible through normal gameplay, now have no model rather than appearing identical to either acacia or dark oak logs.

1.10.0beta 1.10.0.3 The item IDs for wood blocks have changed from positive to negative.
Oak wood: 17:12 -> -212
Birch wood: 17:14 -> -212:2
Spruce wood: 17:13 -> -212:1
Jungle wood: 17:15 -> -212:3
Acacia wood: 162:12 -> -212:4
Dark oak wood: 162:13 -> -212:5
1.20.70Preview 1.20.70.22 The different wood type block states for the wood ID have now been split up into their own IDs.
Birch wood: -815
Spruce wood: -814
Jungle wood: -816
Acacia wood: -817
Dark oak wood: -818
