The Minecraft Wiki is possible to use without access to the internet using ZIM files. ZIM files preserve the majority of the wiki's content in a compact manner which includes page content, images, and videos. Additional work has been put into making crafting recipes and some other interactive elements of the Minecraft Wiki work in ZIM.

Using ZIM files

[edit source]

ZIM is an open format that uses the .zim file extension. A singular ZIM file contains a snapshot of the wiki's content and can be viewed by multiple applications. The most popular, multi-platform and feature complete ZIM browser is Kiwix. It is available for Windows, macOS, and Linux systems as well as major mobile platforms such as Android, iOS, and iPadOS. Additionally, Kiwix can be used as a browser extension or server, letting you host its contents to everyone on a local network.

Obtaining the ZIM file

[edit source]

The easiest way to obtain English Minecraft Wiki ZIM files is through searching "Minecraft" in the Kiwix interface. The English Minecraft Wiki "book" is also included in the default Kiwix online library and is directly downloadable in the client.

ZIM files are available for the following Minecraft Wiki languages:

Language Interval[note 1] Download Size (approximate)
English Quarterly library.kiwix.org[note 2] (preview) 1.8 GiB
Chinese Manually started library.kiwix.org (preview in link) 1.1 GiB
  1. ↑ Snapshots of wiki contents are being generated periodically or manually
  2. ↑ It is recommended to use the larger Minecraft Wiki ZIM file available on Kiwix as it contains more media and interactive content. The other file will be deprecated in the future.

Limitations

[edit source]

To make the ZIM file as accessible as possible there are some trade-offs involved that need to be kept in mind:

  • ZIM files do not contain images in full resolution (only thumbnails).
  • Just like the live version, the snapshot may contain vandalized content. Snapshot generation is automated and unable to discern between vandalized versions of an article and an appropriate one.
  • The default wiki theme at the time of generation is used, and cannot be changed.

Issues

[edit source]

Any issues pertaining to the Minecraft Wiki's ZIM files should be reported on the talk page.
